# Vertical Navigation Bar

A simple and responsive Vertical Navigation Bar created using HTML and CSS. This project demonstrates a clean sidebar navigation menu commonly used in modern websites, dashboards, and web applications.

## Features

- Clean and modern UI
- Vertical sidebar navigation
- Responsive design
- Smooth hover effects
- Easy-to-understand code structure
- Built using pure HTML and CSS

## Technologies Used

- HTML5
- CSS3

## Project Purpose

This project was built to practice:

- HTML structure and semantic elements
- CSS styling and layouts
- Navigation menu design
- Responsive web design principles


## How to Run

1. Clone or download the repository.
2. Open index.html in your browser.
